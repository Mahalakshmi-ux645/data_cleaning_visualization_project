# data_cleaning_visualization_project
A Data Cleaning and Visualization project using Python, Pandas, Matplotlib, and Seaborn. The project includes handling missing values, removing duplicates, detecting outliers, and creating visualizations to derive meaningful insights from employee data through exploratory data analysis.
# Data Cleaning and Visualization Project

Tools Used:
- Python
- Pandas
- Matplotlib
- Seaborn

Project Tasks:
- Handling missing values
- Removing duplicates
- Detecting outliers
- Creating visualizations

Visualizations:
- Bar Chart
- Pie Chart
- Histogram
- Box Plot

Insights:
- IT department has the highest number of employees.
- Missing values were handled successfully.
- Duplicate records were removed.
- Salary distribution was analyzed.
- Outliers were identified using a box plot.
